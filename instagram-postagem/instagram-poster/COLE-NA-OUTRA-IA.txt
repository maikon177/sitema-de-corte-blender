CONTEXTO DO SISTEMA DE AUTO-POSTAGEM NO INSTAGRAM (Pata3D)
(cole isto inteiro para a IA se situar — ela NÃO precisa mais me perguntar o básico)

== O QUE É ==
Programa em Python que posta sozinho no Instagram (feed + stories), com legenda
gerada por IA. Já está instalado e rodando numa VPS. Usa a API OFICIAL do
Instagram (Graph API) — não é login/senha, é token de acesso.

== COMO FUNCIONA (a cada execução) ==
Para cada conta ativa, ele pega 1 foto da fila e:
1. Edita a imagem para feed e para stories (Pillow)                 -> editor.py
2. Gera a legenda com Google Gemini, analisando a imagem            -> legenda.py
3. Sobe a imagem no ImgBB para ter uma URL pública                  -> uploader.py
4. Posta no feed + stories pela Graph API (cria container, publica) -> instagram.py
5. Salva métricas em dados/historico.json e move a foto p/ publicadas/ -> main.py
Roda 1 foto por conta por execução. Arquivo principal: main.py
  - python main.py              -> posta
  - python main.py --so-analise -> só métricas, não posta

== APIS/CHAVES QUE PRECISA (ficam no .env; valores NÃO estão aqui por segurança) ==
- Instagram Graph API -> variáveis: IG_USER_ID_1, IG_ACCESS_TOKEN_1, IG_USER_ID_2, IG_ACCESS_TOKEN_2
    (token da Meta: developers.facebook.com -> app -> Instagram -> gerar token longo ~60 dias)
- Google Gemini       -> variável:  GEMINI_API_KEY   (pegar em https://aistudio.google.com/apikey)
- ImgBB (host imagem) -> variável:  IMGBB_API_KEY    (pegar em https://api.imgbb.com)
Outras: CONTAS_ATIVAS (1, 2 ou 1,2), IG_PASTA_1/_2 (pasta em fotos/), IG_NICHO_1/_2,
        NOME_MARCA, IDIOMA_LEGENDA.
Dependências Python: pillow, google-genai (SDK NOVO, "from google import genai"), requests, python-dotenv.
